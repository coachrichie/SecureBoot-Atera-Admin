# Betriebsgrenzen

- Kein API-Token und keine Atera-Schnittstelle erforderlich.
- Der lokale Phasenplaner startet keine Atera-Prozesse.
- Firmware wird nicht durch dieses Paket aktualisiert.
- Windows Server werden nicht über den Client-Handoff aktualisiert.
- `-Force` blockiert bei unbekanntem oder nicht bestätigtem BitLocker-Escrow.
- Event 1795, `UEFICA2023Error` oder wiederholtes `HANDOFF_FAILED` sind Stop-Kriterien.
